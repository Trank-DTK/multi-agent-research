# 正式前端接入记录

用户已认可 immersive 概念并要求完成后推送 GitHub。本轮将原型接入实际 Vue 应用。

## 最终行为

- `/` 是公开官网：原生 Canvas 粒子球、轨道、滚动渐现、玻璃导航、产品截图透视和研究流程展示。
- `/login`、`/register` 使用同风格认证界面，调用原有后端接口；不含原型的免校验体验入口。注册可选姓名字段保留，密码提示与当前 Django 最低 8 位规则对齐。
- 登录成功进入 `/dashboard`。所有既有工作区路由仍需登录；已登录用户访问认证页进入工作台。账户菜单可返回产品首页。
- 工作区使用更安静的深蓝面板、紧凑工具入口和细化的对话样式；工具搜索和实际业务接口保留。
- 公共样式全部限定在 `.public-shell`，动画名使用 `public-` 前缀。没有新增运行依赖或远程字体。
- 官网可暂停动态效果，尊重系统减少动态偏好；Canvas 在离屏/后台暂停，组件卸载取消帧、监听器和观察器。认证请求与跳转计时器同样在卸载时释放。

## 验证证据

- `node --test frontend/tests/*.test.js`：13 项通过，涵盖真实 Vue 表单请求参数、重复提交、等待状态、token/跳转、卸载取消，以及路由权限、Canvas 生命周期、Markdown、流式解码。
- 变更文件 ESLint：通过。新增公共 CSS 的 414 条选择器规则全部通过限域自查。
- `npm run build`：生产构建与 `vue-tsc` 通过；PWA 构建通过。现有较大公共包和图表包仍有体积提示。
- 独立只读代码审查：未发现阻止提交的确定缺陷。
- 未运行本轮可执行浏览器验收或真实后端账户注册。Docker 当前未启动；以上表单测试使用隔离的请求替身，不接触用户账户或模型密钥。

## 设计自查

保留实际 Logo 和真实组件截图，截图标注演示数据，无虚构产品指标。官网用大字与空间场景组织视觉焦点；认证页延续同一配色、字体和材质。工作区降低动效与装饰密度，长文本区域使用可读文字与表面层级。CSS 包含窄屏布局、键盘焦点、明暗主题与减少动态适配。原型中的 Tweaks 与体验账号逻辑未进入正式页面。

提交范围仅前端和本轮设计记录。工作区原有部署、环境变量、后端与 Nginx 未提交修改不随本轮推送。
