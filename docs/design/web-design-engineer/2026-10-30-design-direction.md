# 精密科研工作台 · 设计方向（已确认）

## Design Read
- Artifact：现有科研协作平台的前端页面。
- Audience：需要长时间阅读、处理文献/数据、组织论文的科研用户。
- Visual language：精密科研仪器与专业工作站；深海蓝、冰蓝、精细排版与明确状态。
- Mode：Redesign · Preserve，保留品牌和产品操作契约。
- Visual variance：4/10，导航和任务页使用稳定网格；仅首页采用有节奏的组合。
- Motion intensity：3/10，仅 hover、focus、切换和真实加载反馈，不持续播放装饰动画。
- Information density：7/10，使常用任务、资料、正文和编辑操作更容易进入首屏。
- Asset dependence：3/10，使用现有真实 Logo 与界面结构，科技感主要来自类型、材质和布局。
- Brand fidelity：9/10，保留蓝色身份、菜单、路由、内容与明暗模式。

## Design Decisions
- Anchor：根据现有产品定制，不复制其他品牌或新增通用模板。
- 深色：背景 #080F1D；面板 #101C2E；正文 #E8EFFB；次级文字 #A4B5CF；蓝色 #5B9CFF；冰蓝 #8EDBED。
- 亮色：背景 #F3F6FC；面板 #FFFFFF；正文 #172B48；次级文字 #5B6F8C；主蓝 #2867CE；冰蓝用于首页深色主视觉。
- 强调策略：蓝色表示可操作与选中；冰蓝集中在主视觉；警告/错误保留语义色。减少无业务意义的彩色工具卡。
- Typography：标题使用 Bahnschrift + Microsoft YaHei 的本机字体组合；正文使用 Microsoft YaHei / PingFang SC；数字/少量技术元信息使用 Cascadia Code / Consolas。无外部字体网络依赖。
- 字号：桌面主标题 32px、任务页标题 28–30px、正文 14–15px/1.8、辅助信息 12px；手机标题 24–26px、正文保持可读。
- Spacing：以 8px 为基础，8/16/24/32/48；控件内部间距允许 4px 半步。
- Radius：控件 10px；任务面板 16px；首页主视觉 24px；圆形仅用于头像/科研示意。
- Elevation：数据正文保持平面；面板低阴影；浮层中阴影；悬停仅局部升高。
- Motion：160–220ms，ease-out，位移不超过 2px；降低动效偏好下取消位移。

## 这轮具体改进
1. 首页：减少重复英文小标签与装饰说明，收紧主视觉、突出研究动作；保留科研关系图，降低装饰密度。
2. 全局：字体、圆角、间距、面板和按钮使用清晰的语义 tokens；合并散落的固定色。
3. 聊天/文献：统一标题栏、资料选择、消息排版、输入区与加载/错误显示；保持 Markdown 的表格和代码局部滚动。
4. 数据/协作/写作：完善工作区的层次、工具栏、选中态与密度；使任务页面具备同一产品的完成度。
5. 明暗与窄屏：保持已有主题选择，所有装饰不覆盖正文或拦截操作；内容合理换行，不截断重要信息。

## Remove / Preserve
Remove：无真实状态支持的装饰点、重复的英文眉题、仅为填空的说明、过多彩色强调。
Preserve：品牌资产、菜单和路由、输入输出逻辑、真实数据、认证、流式、Markdown、删除确认、编辑能力。
