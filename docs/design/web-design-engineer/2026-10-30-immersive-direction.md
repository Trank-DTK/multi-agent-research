# 官网 / 认证 / 工作区 · 高动效视觉概念

本轮依据用户对第一稿“普通、缺少高级感”的反馈迭代草稿。

## 新的页面结构
官网首页：showcase/index.html；登录/注册：同页 #login/#register；进入软件：showcase/experience.html，保留当前工作区的导航和布局。

## Design Read
官网为 Redesign · Overhaul，视觉变化 7、动效 7、密度 4、素材依赖 5、品牌保持 9。认证页动效 4、密度 6，与官网同一材质。工作区采用 Preserve，动效 3、密度 7，避免持续动画影响阅读。

## 设计与动效
深空蓝 #050812、面板 #0C1321、蓝 #79A6FF、冰蓝 #A5E8F3。使用现有 Logo；使用真实组件截图，明确标注界面验证数据，不虚构指标或在线状态。标题原生 Bahnschrift/微软雅黑，8px 间距体系，官网 50–88px 大字，任务区 25–32px。

首屏为 Canvas 三维投影粒子场，轨道/稀疏连接表达研究证据网络，鼠标移动影响空间角度。粒子在离开视口、页面不可见时停止，系统减少动效和 Tweaks 静态模式均有降级。

官网具备分行入场、滚动渐现、导航收缩与玻璃背景、按钮光带、软件截图透视层、进度细线。动效集中在官网与状态反馈，工作区以明晰排版、精细面板、统一强调色提升质感。

## 交互边界
登录注册为明确标注的预览流程，可以留空进入工作区。不发送、校验、保存账号/密码，不调用后端。正式整合时继续使用现有认证接口和字段。

静态自查与脚本语法/本地预览连通检查；未运行可执行浏览器验收。该稿仍用于用户确认视觉与动效方向，尚未覆盖现有产品代码。

## 确认与正式接入
用户回复“不错不错”，确认新版官网、认证页和工作区的视觉方向。继续接入正式 Vue 页面；真实认证与现有 API 合约保持。用户明确要求完成后推送 GitHub。
