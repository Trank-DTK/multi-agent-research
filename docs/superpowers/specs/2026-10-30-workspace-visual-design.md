# 科研工作台视觉升级

用户要求：进一步优化前端，具备高级感和科技感，并明确要求继续执行。

采用现代科研控制台方向。保留蓝色品牌及用户的明暗模式偏好，以深海军蓝、冰蓝、精细边框、少量青色光晕、CSS/SVG 科研关系图表达科技感。正文、Markdown、表格和编辑区优先保证可读性。

比较方向：强霓虹大屏偏展示，长期阅读负担较重；全白极简缺乏用户要求的科技辨识度；当前选择精致科研控制台，在首页集中表达科技感，在任务页统一材质和信息层次。

范围：首页、侧栏、全局主题与共享控件、聊天空状态/消息/输入框、论文布局细节、登录注册表面。保留所有路由、认证、数据流、模型和编辑行为。不使用虚构统计/在线状态，不引入外部字体/图片或新增运行时依赖。

响应式：248px 桌面导航；1000px 以下使用原移动菜单；390px、768px、1440px 分别检查。保留聊天视口高度，表格与代码块局部横向滚动。装饰不拦截鼠标，支持 reduced motion。

实现决策由本轮执行确定：颜色、间距、图形细节、轻量 hover 动效。验证使用构建、既有测试和浏览器截图检查，避免为纯样式编写镜像实现的测试。
